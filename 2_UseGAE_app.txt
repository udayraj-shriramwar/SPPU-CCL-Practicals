# EXPLANATION


## 1. Create Project Folder

# 2. hello.py File

```python
from flask import Flask
```

## Word by Word

* `from`

  * Used to import something from a module/package.

* `flask`

  * Flask library/module used for web development.

* `import`

  * Keyword used to bring functionality into program.

* `Flask`

  * Main Flask class used to create web application.

➡️ This line imports Flask class from Flask library.

---

```python
app = Flask(__name__)
```

## Word by Word

* `app`

  * Variable name storing Flask application object.

* `=`

  * Assignment operator.

* `Flask()`

  * Creates Flask web application object.

* `__name__`

  * Special Python variable.
  * Represents current file name/module name.
  * Flask uses it to know where application is running.

➡️ This line creates the web application.

---

```python
@app.route("/")
```

## Word by Word

* `@`

  * Decorator symbol in Python.

* `app.route()`

  * Used to define URL path.

* `"/"`

  * Root/home page URL.

➡️ Means whenever user opens homepage `/`, run the next function.

---

```python
def hello():
```

## Word by Word

* `def`

  * Keyword used to define function.

* `hello`

  * Function name.

* `()`

  * Function parameters section.

* `:`

  * Starts function block.

➡️ Function named `hello` is created.

---

```python
return "Hello World from Google App Engine!"
```

## Word by Word

* `return`

  * Sends output back to browser.

* `"Hello World from Google App Engine!"`

  * Text displayed on webpage.

➡️ Browser shows this message.

---

```python
if __name__ == "__main__":
```

## Word by Word

* `if`

  * Conditional statement.

* `__name__`

  * Current module name.

* `==`

  * Comparison operator.

* `"__main__"`

  * Means file is directly executed.

➡️ Checks whether file is run directly.

---

```python
app.run(host="127.0.0.1", port=8080, debug=True)
```

## Word by Word

* `app.run()`

  * Starts Flask server.

### Parameters

* `host="127.0.0.1"`

  * Localhost/IP address.
  * Runs app on local computer.

* `port=8080`

  * Port number where app runs.

* `debug=True`

  * Enables debug mode.
  * Automatically reloads app after changes.
  * Shows errors properly.

➡️ Starts web application server.

---

# 3. app.yaml File

```yaml
runtime: python39
```

## Explanation

* `runtime`

  * Specifies programming environment.

* `python39`

  * Uses Python 3.9 runtime on Google App Engine.

➡️ Tells GAE to use Python 3.9.

---

```yaml
entrypoint: gunicorn -b :$PORT main:app
```

## Word by Word

* `entrypoint`

  * Starting command for application.

* `gunicorn`

  * Production web server for Python apps.

* `-b`

  * Means bind server.

* `:$PORT`

  * Uses port provided by Google App Engine.

* `main:app`

  * `main`

    * Python file name (`main.py`)
  * `app`

    * Flask application object.

➡️ Starts Flask app using Gunicorn server.
