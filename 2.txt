2. Create GitHub Repository then:

Using GitHub 
Commands:

git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin YOUR_GITHUB_LINK
git push -u origin main



3. Deploy Using AWS Amplify

Using AWS Amplify

Steps
Login to AWS Console
Search “Amplify”
Click “Create App”
Select GitHub
Authorize GitHub
Select repository
Click Next
Keep default settings
Click Save and Deploy

4. Output

AWS gives deployed website URL like:

https://main.xxxxxx.amplifyapp.com

Open URL → website runs successfully.





































WHAT TO SAY IN VIVA

“Which cloud model is used?”
Answer: PaaS (Platform as a Service)

“Why Amplify?”
Answer: Amplify provides easy deployment, hosting, CI/CD integration, scalability, and serverless hosting.

“What is deployment?”
Answer: Deployment means making application available on internet/server for users.
