#EXPLANATION


# 4. Find a procedure to transfer files from one Virtual Machine to another Virtual Machine

This practical shows how to transfer a file from **VM1** to **VM2** using the **SCP (Secure Copy Protocol)** command in Linux.

---

# Step 1: Download and Install Oracle VirtualBox

### Meaning

* **Oracle VirtualBox** = software used to create and run virtual machines.
* **Virtual Machine (VM)** = a computer running inside another computer.

You will create:

* VM1
* VM2

Both run Ubuntu Linux.

---

# Step 2: Download Ubuntu VMDK Image

### Meaning

* **Ubuntu** = Linux operating system.
* **VMDK** = Virtual Machine Disk file.
* It contains the operating system files.

This file acts like the hard disk of the VM.

---

# Step 3: Launch VirtualBox and Create New VM

## Open VirtualBox

Launch the VirtualBox software.

---

## Click on New

Used to create a new virtual machine.

---

# Enter:

## Name of VM : VM1

* Gives your VM a name.
* VM1 means Virtual Machine 1.

---

## OS → Linux

### Meaning

* OS = Operating System.
* Select Linux because Ubuntu is Linux-based.

---

## OS Version → Ubuntu (64-bit)

### Meaning

* Ubuntu operating system.
* 64-bit version supports modern systems.

---

## specify virtual hardware → Base Memory → 1024 MB

### Meaning

* RAM assigned to VM.
* 1024 MB = 1 GB RAM.

This memory is temporarily shared from your real computer.

---

## Use an existing virtual hard disk file → Browse .vmdk file

### Meaning

* Instead of creating a new disk,
* use the downloaded Ubuntu VMDK file.

Browse and select the `.vmdk` file.

---

## Finish

Completes VM creation.

---

# SIMILARLY CREATE VM2

Same steps are repeated.

Only difference:

```text
Name of VM : VM2
```

VM2 means second virtual machine.

---

# Configure Network

---

## Open VirtualBox:

File → Tools → Network

### Meaning

Used to manage networking settings for VMs.

---

## Open the NAT Networks tab → Create +

### Meaning

* NAT = Network Address Translation.
* Allows VMs to communicate with each other and internet.

### Create +

Creates a virtual private network.

---

## Apply

Saves network settings.

---

# Attach Both VMs to NAT Network

---

## click VM1 → Settings → Network → Attached To → NAT Network

### Meaning

Connects VM1 to NAT network.

---

## click VM2 → Settings → Network → Attached To → NAT Network

### Meaning

Connects VM2 to same NAT network.

Now both VMs are on same network and can communicate.

---

# Launch Both Virtual Machines

Click **START** for:

* VM1
* VM2

Ubuntu operating system will boot.

# Transfer File Using SCP

## Command

```bash
scp transfer.txt vagrant@10.0.2.3:/home/vagrant
```

# Word-by-Word Explanation

| Part          | Meaning                                |
| ------------- | -------------------------------------- |
| scp           | Secure Copy command                    |
| transfer.txt  | File to send                           |
| vagrant       | Username of destination VM             |
| @             | “at” symbol connecting username and IP |
| 10.0.2.3      | IP address of VM2                      |
| :             | Separates IP and path                  |
| /home/vagrant | Destination folder                     |

---

Copy:

```text
transfer.txt
```

from VM1

to:

```text
/home/vagrant
```

folder in VM2 securely over network.

# VIVA

# 20 Important Viva Questions with Answers

## File Transfer Between One VM to Another VM Using SCP

---

## 1. What is a Virtual Machine (VM)?

A Virtual Machine is a software-based computer that runs inside another computer.
It behaves like a real computer with its own OS, RAM, storage, and network.

---

## 2. What is Oracle VirtualBox?

VirtualBox is virtualization software used to create and run virtual machines on a physical computer.

---

## 3. What is Ubuntu?

Ubuntu is a Linux-based operating system commonly used for servers, cloud computing, and virtual machines.

---

## 4. What is a VMDK file?

VMDK stands for Virtual Machine Disk.
It is a virtual hard disk file used by virtual machines.

---

## 5. Why do we create two VMs in this practical?

Two VMs are required so that files can be transferred from one machine (VM1) to another machine (VM2).

---

## 6. What is virtualization?

Virtualization is the technology of creating virtual versions of computers, storage, or networks using software.

---

## 7. What is NAT Network in VirtualBox?

NAT Network allows multiple VMs to communicate with each other and access the internet through the host machine.

---

## 8. Why are both VMs connected to the same NAT Network?

Both VMs must be on the same network so they can communicate and transfer files.

---

## 9. What is an IP address?

An IP address is a unique numerical address assigned to a device in a network for communication.

Example:

```text
10.0.2.3
```

---

## 10. What is the use of `ifconfig` command?

`ifconfig` displays network configuration details such as:

* IP address
* Network interface
* Status of network

---

## 11. What is `eth0`?

`eth0` is the Ethernet network interface of the Linux system.

---

## 12. What is SCP?

SCP stands for Secure Copy Protocol.
It is used to securely transfer files between systems over a network.

---

## 13. Why is SCP called secure?

Because SCP uses SSH (Secure Shell) encryption for secure communication and file transfer.

---

## 14. Explain the SCP command used in the practical.

```bash
scp transfer.txt vagrant@10.0.2.3:/home/vagrant
```

### Meaning:

* `scp` → secure copy command
* `transfer.txt` → source file
* `vagrant` → username of destination VM
* `10.0.2.3` → IP address of destination VM
* `/home/vagrant` → destination folder

---

## 15. What is the purpose of the `touch` command?

`touch` is used to create an empty file.

Example:

```bash
touch transfer.txt
```

---

## 16. What is Nano editor?

`nano` is a simple command-line text editor in Linux used to create and edit files.

---

## 17. What does the `ls` command do?

`ls` lists all files and folders in the current directory.

---

## 18. What is the purpose of the `cat` command?

`cat` displays the contents of a file.

Example:

```bash
cat transfer.txt
```

---

## 19. What does `sudo` mean?

`sudo` means “Super User Do.”
It runs commands with administrator/root privileges.

---

## 20. What happens if the wrong IP address is used in SCP?

The file transfer will fail because SCP will not be able to connect to the destination VM.

Example errors:

* Connection refused
* Host unreachable
* No route to host
