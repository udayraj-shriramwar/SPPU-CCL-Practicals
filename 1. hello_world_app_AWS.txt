# PART 3 — Create Addition App

## `addition.html`


<!DOCTYPE html>
<html>
<head>
    <title>Addition App</title>
</head>
<body>

<h2>Addition Program</h2>

<input type="number" id="a" placeholder="Enter first number">
<input type="number" id="b" placeholder="Enter second number">

<button onclick="add()">Add</button>

<h3 id="result"></h3>

<script>
function add() {
    let x = Number(document.getElementById("a").value);
    let y = Number(document.getElementById("b").value);

    document.getElementById("result").innerHTML =
        "Addition = " + (x + y);
}
</script>

</body>
</html>

# PART 4 — Push to GitHub

## Terminal Commands

```
git init
git add .
git commit -m "AWS Web App"
```

Create GitHub repository then:

```
git remote add origin YOUR_GITHUB_LINK
git push -u origin master
```

If master fails:

```
git push -u origin main
```
