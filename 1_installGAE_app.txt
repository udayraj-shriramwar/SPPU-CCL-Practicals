Meaning:
Install Flask version 3.0.0 only.

---

## Line 2

```txt
gunicorn==21.2.0
```

* `gunicorn` → production web server for Python apps.
* `==` → exact version.
* `21.2.0` → version number.

Meaning:
Install Gunicorn version 21.2.0.

# `hello.py`

```python
from flask import Flask
```

## Word by Word

* `from` → import specific item from module.
* `flask` → Flask library/module.
* `import` → bring code/library into current program.
* `Flask` → Flask class used to create app.

Meaning:
Import Flask class from Flask library.

---

```python
app = Flask(__name__)
```

## Word by Word

* `app` → variable name storing Flask app object.
* `=` → assignment operator.
* `Flask()` → creates Flask application.
* `__name__` → special Python variable containing current file name/module name.

Meaning:
Create Flask application object.

---

```python
@app.route("/")
```

## Word by Word

* `@` → decorator symbol.
* `app.route()` → defines URL route/path.
* `"/"` → home page route.

Meaning:
When user visits homepage `/`, execute next function.

---

```python
def hello():
```

## Word by Word

* `def` → define function.
* `hello` → function name.
* `()` → function parameters (none here).
* `:` → start of function block.

Meaning:
Create function named `hello`.

---

```python
return "Hello World from Google App Engine!"
```

## Word by Word

* `return` → send output back.
* `"Hello World from Google App Engine!"` → string displayed in browser.

Meaning:
Browser shows this message.

---

```python
if __name__ == "__main__":
```

## Word by Word

* `if` → condition statement.
* `__name__` → current module name.
* `==` → comparison operator.
* `"__main__"` → means file is running directly.

Meaning:
Run below code only if file executed directly.

---

```python
app.run(host="127.0.0.1", port=8080, debug=True)
```

## Word by Word

* `app.run()` → starts Flask server.
* `host="127.0.0.1"` → localhost IP address.
* `port=8080` → application runs on port 8080.
* `debug=True` → enables debug mode for error checking.

Meaning:
Start local web server.

---

# `app.yaml`

```yaml
runtime: python39
```

## Word by Word

* `runtime` → specifies programming environment.
* `python39` → Python 3.9 runtime.

Meaning:
Use Python 3.9 on Google App Engine.

---

```yaml
entrypoint: gunicorn -b :$PORT main:app
```

## Word by Word

* `entrypoint` → startup command for app.
* `gunicorn` → web server.
* `-b` → bind option.
* `:$PORT` → use system-assigned port.
* `main:app` → file name `main.py` and Flask object `app`.

Meaning:
Start application using Gunicorn server.

---

```yaml
instance_class: F1
```

* `instance_class` → server machine type.
* `F1` → free/basic instance type.

Meaning:
Use small free instance.

---

```yaml
automatic_scaling:
```

* `automatic_scaling` → automatically manage instances.

---

```yaml
min_instances: 0
```

* `min_instances` → minimum running servers.
* `0` → no server kept active always.

---

```yaml
max_instances: 1
```

* `max_instances` → maximum running servers.
* `1` → only one instance allowed.

# VIVA

# Viva Questions – Google App Engine + Flask

## Basic Viva Questions

### 1. What is Google Cloud Platform App Engine?

Google App Engine (GAE) is a Platform as a Service (PaaS) used to deploy and run web applications without managing servers.

---

### 2. What is Flask?

Flask is a lightweight Python web framework used to create web applications and APIs.

---

### 3. What is PaaS?

PaaS (Platform as a Service) provides a platform to develop, run, and deploy applications without managing infrastructure.

Examples:

* Google Cloud Platform App Engine
* Amazon Web Services Elastic Beanstalk
* Microsoft Azure App Service

---

### 4. What is Google Cloud SDK?

Google Cloud SDK is a command-line toolkit used to manage Google Cloud services.

---

### 5. What is the use of `gcloud init`?

It initializes Google Cloud SDK and connects your Google account and project.

---

### 6. What is `app.yaml`?

`app.yaml` is the configuration file used by Google App Engine to define runtime, scaling, and startup settings.

---

### 7. What is runtime in `app.yaml`?

Runtime specifies the programming environment.

Example:

```yaml
runtime: python39
```

means Python 3.9 environment.

---

### 8. What is Gunicorn?

Gunicorn is a Python WSGI HTTP server used to run Flask applications in production.

---

### 9. Why do we use `requirements.txt`?

It stores all required Python packages and versions for the project.

---

### 10. What is the purpose of `@app.route("/")`?

It maps a URL path to a Python function.

`"/"` represents the homepage route.

---

### 11. What is localhost?

`127.0.0.1` is called localhost.
It refers to the current computer.

---

### 12. What is port 8080?

A port is a communication endpoint.
Port 8080 is commonly used for web applications.

---

### 13. What is debug mode in Flask?

Debug mode automatically reloads the app and shows detailed error messages.

```python
debug=True
```

---

### 14. What is the use of `return` in Flask?

`return` sends response data back to the browser.

---

### 15. Difference between Flask and Django?

| Flask          | Django          |
| -------------- | --------------- |
| Lightweight    | Heavy framework |
| Simple         | Feature-rich    |
| Flexible       | Built-in tools  |
| Small projects | Large projects  |

---

### 16. What is WSGI?

WSGI (Web Server Gateway Interface) connects Python web apps with web servers.

---

### 17. What is automatic scaling?

Automatic scaling increases or decreases app instances based on traffic.

---

### 18. What is instance class `F1`?

`F1` is a free/basic instance type in Google App Engine.

---

### 19. What is cloud computing?

Cloud computing means using servers, storage, and services over the internet.

---

### 20. What is deployment?

Deployment means uploading and running an application on a server/cloud platform.

---
